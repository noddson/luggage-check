# luggage-check

A static web app that estimates whether selected luggage sets will fit in configured vehicle cargo zones.

## Flattened project layout

The repository has been flattened so the runtime and tooling files are at the root level (while keeping `configs/` and `docs/`):

```text
.
├─ app.js                    # browser application logic
├─ styles.css                # browser styling
├─ index.html                # GitHub Pages/root app shell
├─ fitEstimator.js           # browser fit estimator module
├─ fitEstimator.node.js      # Node-side estimator module used by scripts
├─ loadConfigs.js            # Node config loaders
├─ generate-vehicle-index.mjs
├─ validate-configs.mjs
├─ smoke-app.mjs
├─ serve-app.mjs
├─ configs/
│  ├─ luggage/
│  └─ vehicles/
└─ docs/
   └─ code-documentation.md
```

## GitHub Pages loading

The app is now root-relative for this repository layout:

- `index.html` loads `./app.js`
- `app.js` loads config JSON from `./configs/...`

This supports loading from:

- `https://noddson.github.io/luggage-check`

## Run locally

```bash
npm start
```

Open <http://localhost:4173>.

## Checks

```bash
npm run validate:vehicle-index
npm run validate:configs
npm run smoke:app
npm run check
```

## Notes

- `configs/vehicles/index.json` is generated by `generate-vehicle-index.mjs`.
- Keep `configs/` as the source of truth for luggage and vehicle definitions.
- `docs/` remains unchanged for project documentation.
